# ChainPeregrine

ChainPeregrine is a cloud-based system that enables real-time data processing and auto-scaling for high-performance cryptocurrency transaction validation.

ChainPeregrine is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainPeregrine.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

ChainPeregrine is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
